Codex → Claude Desktop Bridge 0.3.0 — macOS preview

安装 / Install
1. Apple Silicon (M-series) 下载 arm64；Intel 下载 x86_64。最低 macOS 13。
   Choose arm64 for Apple Silicon or x86_64 for Intel; macOS 13+.
2. 打开 DMG，把 Codex Claude Bridge.app 拖到 Applications。
   Open the DMG and drag the app to Applications, then eject the disk image.
3. 从“应用程序”打开。应用已内置 Python，不用安装 Python、Homebrew 或 Xcode。
   Launch from Applications. Python is bundled; no compiler or Homebrew required.

首次打开 / First launch
本预览版为 ad-hoc 签名，尚未经过 Apple Developer ID 签名或公证。
macOS Gatekeeper 可能阻止首次打开。确认下载来源和 SHA256 后，可按 Apple
官方说明在 System Settings → Privacy & Security 中对这个应用选择 Open Anyway。
管理设备可能不允许此操作。请勿关闭 Gatekeeper 或移除系统级保护。
https://support.apple.com/en-us/102445
This preview is ad-hoc signed, not Developer ID signed or notarized. Gatekeeper
may block first launch. Follow Apple's documented per-app confirmation only if
you trust this download; managed Macs may not allow it. Do not disable Gatekeeper.

连接 / Connect
- 先打开 Codex Desktop 和已登录的 Claude Desktop Code。
- 输入一个本机 Codex 对话 ID 和同一项目目录，然后保存绑定。
- 点击“打开 Claude 待命”，在 Claude 的 Environment 中确认实际工作目录，
  按正常 MCP 流程允许连接，再发送待命提示。显示“等待故障”才算接通。
- 接续期间不要同时重试 Codex 源任务。暂停只停止新的交接。
- 更新应用前先暂停、结束正在执行的接续并退出旧应用；替换后重新保存绑定，
  并重新打开 Claude 待命。运行目录和配置不存放在应用包里。

Uninstall: pause and finish active work first. Use the documented MCP uninstall
command to restore the project connector, then remove the app. User state is
kept in ~/Library/Application Support/CodexClaudeBridge/ unless explicitly removed.

This is an experimental integration using a private Codex IPC protocol. The
packaging tests do not establish live overload failover or every OS version.
Source, configuration, uninstall, known limits and reusable standby prompt:
https://github.com/reshuibuduo/codex-claude-desktop-bridge
